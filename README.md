# Alkesh Rahul Shejwal — Portfolio Website

A responsive single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling, colors, layout, project illustrations
- `script.js` — mobile navigation, project filters, dynamic footer year

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Customize before publishing
- Add GitHub repository links and live demos to each project card.
- Add a professional headshot if desired.
- Confirm education and internship dates match your final, verified details.
- Add a downloadable resume link if you want visitors to download a PDF.
- Google Fonts require an internet connection; the page has fallback fonts.

## Publish
You can host this static site on GitHub Pages, Netlify, or Vercel. No backend is required.
